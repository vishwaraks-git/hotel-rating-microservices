# Hotel Rating Microservices

A complete Spring Boot Microservices project.

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Cloud
- Eureka Server
- API Gateway
- Keycloak
- MySQL
- Docker

## Services

1. User Service
2. Hotel Service
3. Rating Service
4. API Gateway
5. Config Server
6. Service Registry

### Start Services
